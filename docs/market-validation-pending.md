# 尚未完成的市場驗證

目前測試屬公式與輸入驗證，不等於歷史市場驗證。

## 每筆驗證必要資料
- 事件起訖日與消息來源
- 同期間基準殖利率（同天期、同貨幣）
- 事件前基金公告的修正存續期間及來源日期
- 事件前後可比的除權息、分割調整價格
- 原幣與台幣分開的價格報酬；匯率與配息分開核算
- 信用利差、非平行殖利率曲線與其他同時發生事件

## 方法
1. 凍結事件前可得參數，避免事後回填。
2. 計算 duration 線性價格變動；記錄與實際價格報酬的百分點誤差。
3. 配息另與實際公告／入帳核對，不用價格報酬推算配息減少。
4. 用多個升息、降息、信用風險事件分開報告偏差與絕對誤差。
5. 保留未用於調整模型的事件作驗證，缺資料案例不可當成零誤差。

未取得完整且可核對的事件資料前，不宣稱通過市場驗證。
